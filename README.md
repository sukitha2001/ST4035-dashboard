# Binary Logistic Regression Explorer (Streamlit)

Interactive Streamlit dashboard demonstrating binary logistic regression concepts, class imbalance handling, and link functions.

## Requirements

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

Open the URL shown by Streamlit in your browser (usually http://localhost:8501).

Controls are in the sidebar: sample size, minority proportion, balancing method, and link function.

All charts and metrics update live with control changes.
